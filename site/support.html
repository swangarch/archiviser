Open-source support

Support.

Get help with installation, skill selection, unexpected behavior, or a proposal for a new architectural workflow.

Maintained by Shuai Wang and project contributors

Ask for help

Open an issue in the Archiviser GitHub repository. Include the skill name, host application, expected behavior, and a minimal reproducible example.

Protect your data

GitHub issues are public. Remove client names, confidential drawings, access credentials, personal data, and proprietary images before posting. A simplified description or redacted screenshot is usually enough.

Response scope

Support covers the Archiviser skill instructions and packaging. Questions about accounts, billing, model availability, or platform outages should be directed to the provider of the AI platform or image tool.

Security

Do not publish exploit details, secrets, or sensitive data in an issue. For a potential security concern, create a minimal report without sensitive payloads and request a private follow-up channel.
