Public plugin policy

Privacy.

Archiviser is a skills-only, open-source plugin. The plugin package does not operate its own server, user accounts, analytics system, or database.

Effective 5 August 2026 · Publisher: Shuai Wang

Data we collect

The Archiviser plugin itself does not collect, receive, or store personal data, prompts, uploaded files, generated images, conversation history, authentication credentials, or payment information.

If you voluntarily post an issue or contribution on GitHub, the information you choose to publish is handled by GitHub and may be publicly visible.

How processing works

Archiviser provides static Markdown instructions that an AI agent can follow. Your prompts, files, and generated outputs are processed by the AI platform and any image-generation or editing tools you enable. Archiviser does not independently receive those materials.

Please review the privacy terms of the platform and tools you use with the plugin.

Website data

The project website is a static GitHub Pages site. Archiviser does not add analytics, advertising trackers, accounts, or first-party cookies. GitHub may process basic request and security logs under its own privacy statement.

Sharing and recipients

Because Archiviser does not collect plugin usage data, it does not sell or share such data with advertisers, data brokers, or other third parties. Data processed by your chosen AI platform or tools is governed by those providers.

Retention

Archiviser retains no prompts, files, images, or usage records. Public GitHub issues and contributions remain on GitHub until edited or removed according to GitHub controls and repository moderation requirements.

Your controls

  • Remove or disable the plugin at any time.
  • Use your AI platform’s controls to manage conversations and uploaded files.
  • Avoid including sensitive information when it is not required.
  • Edit or delete content you posted to GitHub where GitHub permits it.

Children

Archiviser is intended for professional and educational architectural workflows and is not directed to children under 13.

Changes

Material changes will be published on this page with a revised effective date and reflected in the public repository history.

Contact

For privacy questions, open a private-scope request where possible or use the project’s GitHub issue tracker. Do not include confidential personal information in a public issue.
