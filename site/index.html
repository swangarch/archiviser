01 / What this is

A skill teaches an AI
how to do one visual task.

Codex is an AI agent: an assistant that can read your files, follow a selected skill, use an image generator, and return the finished image. You describe the design goal in normal language; the skill gives the AI a clear method and a checklist.

Each skill explains what the AI may change, what must stay fixed, and what to check before delivery. Use Codex, ChatGPT, or another AI agent that can understand and generate images.

03 / Capabilities

See what each
skill can change.

These examples show five practical jobs: create a finished exterior, complete a public interior, replace one object, match several views, or repair a damaged render.

01Generate · Exterior

Create a finished
competition exterior

Turn a massing image, sketch, collage, or basic CG view into a polished exterior while keeping the building readable and credible.

$render-competition-exterior ↗ Scene · Material hierarchy · Human scale · Exposure
02Generate · Public interior

Make a public interior
feel real and occupied

Develop a library, museum, or civic interior with believable materials, daylight, people, circulation, and activity.

$render-public-interior ↗ Program · Activity · Section · Material depth
03Edit · Surgical

Replace one object.
Keep the room unchanged.

Drag the handle to compare the edit. Only the sofa changes; the camera, architecture, lighting, and other furniture stay fixed.

04Control · Multiview

Keep one design consistent
across different views

Generate another camera view of the same room while keeping its architecture, furniture, materials, objects, and lighting consistent.

$match-archviz-multiview ↗ Inventory · Shared anchors · Camera translation · Conflict hierarchy

Repair image quality.
Do not change the design.

Fix noisy textures, broken edges, vegetation, materials, and small geometry while preserving the approved architecture and composition.

04 / Method

How every skill works.

Each specialist has a different purpose, but all follow the same four-part control loop: read the evidence, lock invariants, make the authorized change, and compare the result.

  1. 01

    Read

    Inspect every input and assign its authority.

  2. 02

    Lock

    Declare geometry, design, and objects that cannot drift.

  3. 03

    Make

    Generate or edit only inside the authorized layer.

  4. 04

    Compare

    Validate shared edges, anchors, materials, and scale.

05 / Install

Use it in Codex.

Add the GitHub repository as a Codex plugin marketplace, then install the skills-only plugin. Start a new thread after installation so Codex discovers the new skills.
