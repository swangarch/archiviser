01 / The project

Architectural intent
should come before prompts.

Archiviser is an open collection of architectural reasoning skills for AI agents. It sits between your design intent and an image model: reading the brief, examining the references, identifying constraints, and deciding how the task should be approached.

A skill is not a style preset or a stored magic prompt. It is reusable expertise: a way for the agent to ask the right questions, distinguish what may change from what must stay fixed, and verify that the result still belongs to your project.

02 / Why skills + agents

Every project asks
a different question.

A fixed prompt repeats instructions. An agent interprets the situation. Archiviser gives that interpretation an architectural method.

Traditional image workflow

Start from
a fixed prompt.

  1. Choose a template or preset
  2. Replace keywords for the new scene
  3. Generate and inspect the drift
  4. Rewrite the prompt when context changes

The instructions carry the intelligence. Custom work often means prompt maintenance.

Archiviser workflow

Start from
your intent.

  1. Understand the goal and source material
  2. Reason about authority and constraints
  3. Design a task-specific visual brief
  4. Generate, inspect, and adapt

The agent carries the reasoning. The skill supplies architectural expertise without pre-deciding your answer.

Brief→Understand→Reason→Direct→Verify

06 / Method

Reasoning made operational.

Each specialist has a different purpose, but all protect the same principle: interpret the brief before generating, then validate the result against the design intent.

  1. 01

    Read

    Inspect every input and assign its authority.

  2. 02

    Lock

    Declare geometry, design, and objects that cannot drift.

  3. 03

    Make

    Generate or edit only inside the authorized layer.

  4. 04

    Compare

    Validate shared edges, anchors, materials, and scale.

07 / Install

Bring Archiviser
to your agent.

The current distribution works as an Agent Skills plugin for Codex. The project itself remains model-agnostic: its core is the reasoning method, not one image model or interface.

Codex CLI

Two commands,
one growing toolkit.

The public one-click button will become available after the plugin receives a published or workspace share ID. Until then, these are the official reproducible installation steps.

codex plugin marketplace add swangarch/archiviser
codex plugin add archiviser-skills@archiviser-skills
