# Construction axonometric prompt template

Use case: infographic-diagram.

Primary request: Reconstruct the source project as a precise construction axonometric using parallel projection.

Geometry authority: list the massing, levels, roofs, openings, courtyards, circulation, water, paving, and context that must remain recognizable.

Projection: state the three-quarter orientation, keep verticals vertical, keep major axes parallel, and show the complete project with white margin.

Assembly story: choose roof, envelope, slabs, structure, fit-out, landscape, or a restrained combination.

Exploded layers: name only the coherent systems to move, the direction of displacement, and the fine registration guides that reconnect them.

Line hierarchy: strongest construction boundaries; medium-fine visible edges; fine materials; lighter entourage.

Detail enlargements: request zero to two exact junctions linked to the main drawing.

Avoid: mixed perspective, arbitrary fragments, excessive separation, impossible support, gray shadows, color, blueprint background, dense annotation, invented labels, heavy outlines, text, logos, watermark.

Validation: compare footprints, relative heights, openings, layer registration, joint logic, material direction, and projection consistency with the source.
