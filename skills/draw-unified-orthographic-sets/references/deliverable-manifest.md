# Deliverable manifest

Create one row per requested output before drawing.

| ID | View type | Level/direction/cut | Scale | File | Geometry source | Status |
| --- | --- | --- | --- | --- | --- | --- |
| P-00 | site plan | north up | 1:500 | site-plan | geometry ledger | pending |
| P-01 | floor plan | level 00 | 1:200 | ground-floor-plan | geometry ledger | pending |

Default to separate files. Add a `summary-sheet` row only when explicitly requested, and list the completed source files it places. Never treat a sheet crop as the only copy of a drawing.

Record a shared graphic standard: page background, cut weight, visible weight, fine weight, material weight, poche convention, font family, title format, scale-bar style, north-arrow style, entourage style, and permitted accent color.
