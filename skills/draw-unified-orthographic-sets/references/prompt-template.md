# Standalone drawing prompt

Primary request: create one named architectural orthographic drawing as a standalone full-resolution asset.

View definition: state site plan, exact level plan, roof plan, viewing direction elevation, or named continuous section cut.

Geometry authority: identify the source or geometry-ledger revision. Lock footprint, grids, levels, walls, structure, openings, stairs, voids, roof, terrain, and fixed objects visible in this view.

Shared graphic standard: white page; compact black cut; medium visible architecture; fine fixtures and landscape; finest sparse material notation. State scale, title, symbol, and entourage conventions if required.

Constraints: orthographic projection; full drawing with margins; no other views on the page unless a summary sheet is explicitly requested.

Avoid: geometry drift, perspective, render shading, dense hatch, fake dimensions, fake text, logos, watermark.

Validation: compare at least five shared anchors with the geometry ledger and adjacent approved views.
