# Delivery checklist

- Each board exists as an independent output at the requested size.
- Optional overview does not replace individual boards.
- Every placed drawing or image traces to an approved source file and revision.
- No source asset was redrawn, stretched, mirrored, or silently altered.
- Plans, sections, elevations, diagrams, and captions remain readable at print size.
- Margins, bleed, gutters, baselines, numbering, and typography match across boards.
- One narrative and one dominant visual are clear on each board.
- Concept text is accurate; drafts and placeholders are identified.
- Resolution and color mode suit the delivery medium.
- No clipped text, unintended crop, fake logo, watermark, or missing linked asset remains.
