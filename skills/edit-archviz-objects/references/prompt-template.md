# Invariant-first edit template

Use case: precise-object-edit

Input image: the exact selected image is the edit target.

Primary request: change only the named object or finish.

Replacement specification:
- geometry and silhouette;
- dimensions and proportion;
- material and texture;
- color and saturation;
- position and orientation;
- lighting response;
- explicit negative examples.

Strict invariants: preserve camera, perspective, architecture, ceiling, walls, openings, floor, fixed joinery, all unmentioned furniture, decor, plants, lighting, palette, and daylight.

Quality: realistic construction, clean edges, coherent material scale, natural contact shadows, neutral white balance.

Avoid: collateral edits, added objects, shifted furniture, architecture drift, style reset, yellow cast, gray wash, HDR, text, logos, watermark.

## Example: flat ceramic wall light

Replace only the existing wall lights with two matching ultra-thin matte-white folded ceramic planes, 3–4 cm projection, concealed mounting, subtle indirect light from one folded edge, no brass, no visible hardware, no cylindrical or round form. Preserve everything else.
