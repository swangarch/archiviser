# Residential design-and-render template

Use case: precise-object-edit or sketch-to-render

Architecture: preserve the stated camera, walls, openings, ceiling levels, fixed joinery, and circulation. If any fixed element is ambiguous, default to preserving it.

Design:
- Establish one focal wall and one continuous low datum.
- Create a seating group with realistic clearances.
- Use one principal timber, one pale mineral material, one textile family, and one controlled accent.
- Keep the ceiling calm with a flat plane, restrained cornice, a sculptural fixture, and a few functional pin lights.
- Prefer integrated storage and sparse surface styling.

Suggested palette: warm ivory plaster, natural oak herringbone, dark walnut, pale honed limestone, oatmeal linen, cognac leather, matte white ceramic, opaline glass, brushed stainless steel.

Lighting: bright soft daylight, neutral white balance, visible material detail, no HDR.

Avoid: architecture drift, oversized blob sofa, round central coffee table in a linear room, blue or teal upholstery unless requested, gold overload, yellow grading, gray wash, cove LEDs, clutter, repeated vases, text, logos, watermark.
